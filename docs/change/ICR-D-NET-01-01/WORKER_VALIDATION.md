# Worker/NTP 수집기 검증

2026-09-10. `python3 -m unittest discover -s tests -v`: **15/15 PASS**.

검증 범위: 고정된 12개 TCP 경로, 잘못된 요청·노드·IP 차단, CP의 제한된 조회 범위, Inventory 그룹/IP/사용자 검사, SSH 접속 옵션, NTP 비밀 설정 제외·신뢰할 수 없는 파일 거절·외부 include 미추적, timeout 부분 출력 보존·마스킹, 출력 잘림 표시, TCP 오류 번호 보존, 수집 완전성과 연결 성공의 분리, 사전 검사 실패 시 증적 압축·체크섬 보존, 소스 변조 탐지.

모의 응답·로컬 임시 파일을 이용한 테스트다. 실제 노드의 방화벽·NTP 조회, 연결 성공, 운영 적용을 검증한 결과는 아니다. 실제 실행은 배포 키트를 ansible01에서 실행해 제출한 증적으로 별도 판단한다. 변경·적용 명령은 구현하지 않았다.

실행 소스는 PR 커밋과 배포 `SOURCE_LOCK.json`으로 연결한다. `WORKER_SOURCE_SHA256SUMS`는 이 변경의 여섯 소스 파일만 포함하며 기존 CP1 키트의 체크섬 파일과 충돌하지 않는다.
